# Gerenciador de Tarefas Caóticas (GTC) 📝

Um mini aplicativo de terminal projetado especificamente para pessoas que só conseguem ser produtivas sob extrema pressão psicológica. Este projeto consome a brilhante biblioteca `Texto Magico Pro` como dependência via submódulos do Git.

## Requisitos
- Python 3.x instalado.

## Como executar o sistema

1. Clone este repositório garantindo a inicialização dos submódulos:
   `git clone --recurse-submodules <LINK_DESTE_REPOSITORIO>`
2. Acesse a pasta do projeto:
   `cd app-tarefas-caoticas`
3. Execute o script principal:
   `python main.py`

## Tecnologias Integradas
O aplicativo utiliza o "Uppercase Protocol" da biblioteca base para transformar tarefas simples em ordens ameaçadoras, garantindo o fim da procrastinação. Além disso, implementa a "Reverse String Technology" como um sofisticado sistema de criptografia visual, impedindo que pessoas passando atrás da sua cadeira saibam o que você está (ou não) fazendo.
